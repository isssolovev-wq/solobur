Лоты

  1. Добавьте или измените лоты и нажмите «Скопировать список для сайта».
  2. На GitHub откройте файл lots.json, нажмите карандаш ✏️, выделите всё (Ctrl+A), вставьте (Ctrl+V) и нажмите Commit changes. В первый раз создайте файл: Add file → Create new file, имя lots.json.
  3. Через 1–2 минуты после сборки в Timeweb список обновится у всех.
